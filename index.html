How to install

  1. Install Fabric or NeoForge for the Minecraft version you want. For Fabric also install Fabric API.
  2. Download the file that matches your loader and Minecraft version.
  3. Put the .jar file in the mods folder of your game, then start the game.
The downloads are served by GitHub. Please download only from this page.
